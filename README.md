# Mini SmartAdvisor

Mini SmartAdvisor is a simplified course scheduling web application created for Engineering Design 2.

The application allows students to add and manage course information, including:

- Course name
- CRN
- Meeting days
- Start time
- End time

Courses are stored in a Supabase database so they remain available after the page is refreshed.

## Features

- Add courses
- View saved courses
- Edit courses
- Delete courses
- Store course information in a database
- Deployed as a web application

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- GitHub
- Netlify

## Database

The application uses Supabase to store course information.

The Courses table stores:

- Course
- CRN
- Days
- Start Time
- End Time

## Deployed Application

https://mini-smartadvisor.netlify.app

## Setup Instructions

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Make sure an internet connection is available so the application can connect to Supabase.

## How to Use

1. Enter a course name.
2. Enter the CRN.
3. Enter the meeting days.
4. Select the start and end time.
5. Click **Add Course**.
6. Use **Edit** to update a course.
7. Use **Delete** to remove a course.

## Project Purpose

This project was created as practice for using AI tools to build software and as a simplified prototype related to the SmartAdvisor Engineering Design project.
